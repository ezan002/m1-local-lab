# 产品方向（最新用户决策）

更新日期：2026-10-10。最新依据为用户本轮转述的会议结论（不是补造的导师逐字原文）。本说明优先于下面保留的 2026-10-01 阶段方向；各项能力是否通过，以[本轮观测验收](historical-observation.md)为准。每个后续阶段开始前，先读取本说明及上一阶段报告。

## 当前目标与核心流程（本次会议更新）

用户随后明确的最终目标是：本地、可扩展的多智能体观测与错误归因平台，以真实轨迹和可复现实验验证，并在执行系统支持时探索恢复与交互调试。当前迭代先推进“固定样本展示 → 已支持格式的多样本登记与核对”；归因的最终目标保留，但不把接入测试通过当作归因有效性的证明，本轮不改冻结协议或扩展归因算法。

接入已有智能体的执行记录，在本机理解各 Agent、模型和工具的交互；只有执行系统确实支持时，才提供编辑、恢复、Replay/Fork。导师最新方向由用户明确转述：优先第三方真实历史，不要求在平台重建 Agent；回归本地 Phoenix，先核实版本能力，再做必要扩展。

当前流程：无 Key 启动观测 → 选择本地获准样本 → 校验、预览数量和缺失 → 脱敏导入独立 Phoenix Project → 读回身份及内容 → 浏览步骤和原文件位置 → 跳转对应 Trace 核对（保留 Project 与 Trace ID 筛选入口）。

- **历史观测**：导入已存在的记录；不产生新任务，不伪造 prompt、调用关系、时间或 checkpoint。
- **实时观测**：接收其他执行系统运行时发出的事件/Span；不等于拥有执行控制权，本轮暂不接入。
- **执行控制**：依赖执行系统保存的可恢复状态和接口。普通日志和 Span ID 不能充当 checkpoint。

## 本轮边界与旧计划调整

沿用 Python、现有原生网页和当前 Phoenix；不升级整套依赖，不引入 Docker 或云端平台。复用旧资产，不默认重写。暂停 Sim 平台选型/拖拽画布、Replay/Fork 大规模改版、并行执行、外部 Agent 编辑和自动归因研发。Sim 等参考不再是本轮交付前提。错误归因隐藏主导航和默认请求，保留后端、恢复入口、数据、协议及冻结结果。原本本地执行保留为次级入口。

## 待确认事项

未来实时接入系统及其可恢复契约尚未选定；更多格式必须逐一取得样本和授权后适配。本轮无需等待这些问题。Who&When 只作本地研究，不把仓库 MIT 许可推定为数据许可。旧计划中的技术可替换原则保留，但**本轮已选择先用当前本地 Phoenix 验证**，不继续平台调研。

## 2026-10-01 阶段方向存档（优先级已由上文调整）

以下是当时的用户方向，不代表本轮仍按这些范围实施。[阶段 1](product-stage1-requirements.md)和[阶段 2](product-stage2-technical-baseline.md)保留历史证据，不倒写其验收结论。

## 产品目标

在原项目上形成易安装、易使用、适合日常分析与导师演示的本地产品。用户应能从新任务看清真实执行的 Agent、工具、输入输出、证据和结果；能检查历史状态，理解暂停/继续、重新执行和修改后分叉，并直观比较分支的共同历史、修改位置与后续结果。界面应清楚解释失败、不可用与操作限制。导入的历史轨迹必须与本项目实际执行的任务区分。

## UI 参考分工

- **Sim：整体视觉与产品感的主要参考。**借鉴清晰的导航和工作区、统一的字体与间距及卡片/按钮/状态样式；先给概要，再按需展开技术详情，避免主页面堆满日志、JSON、内部编号和密集控制项。不照搬无关业务功能。
- **AGDebugger：**参考历史关系、分叉位置与不同尝试的展示。
- **LangSmith Studio：**参考节点检查、历史状态与重跑操作的交互。
- **AutoGen Studio：**参考 Agent 身份、协作过程与产物展示。

这些产品仅作设计参考，不构成安装或集成依赖。进入交互与视觉设计阶段时，须实际查看可访问的 Sim 官方界面示例；若无法访问，明确列出需用户提供的截图，不凭印象宣称已对齐。

## 架构可替换原则

原项目是可复用资产，不是必须保持的最终架构。LangGraph、Phoenix、官方 WebSurfer、现有数据库及前端技术均可评估保留、封装、改造或替换；依据目标覆盖、真实操作效果、本地部署负担、运行成本和维护成本作决定，既不默认沿用，也不默认重写。更换外观不能代替真实执行、历史检查和控制语义。明显增加安装负担、云端依赖或费用的方案必须明示取舍。

## 范围边界

本轮优先处理任务执行与可理解的过程、历史检查、暂停继续、重跑分叉和结果比较。保留已有错误归因代码、研究数据与结果，但错误归因退出本轮主界面重点，不扩展算法研发，也不将未验证的归因效果表述为产品能力。本说明只同步方向，不批准技术迁移或实施改动。
